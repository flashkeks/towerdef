# Gegner und Waves

**Vorab: Das Wiki enthält keine Gegner-HP, keine Geschwindigkeiten, keine HP-Skalierung und keine Wave-Zusammensetzung.** Drei gezielte Suchen (Seiten Enemy Mechanics, Infinite Mode, Raids/Survival, Wiki-Volltext) ergaben nur Eigenschaften und prozentuale Modifier. Siehe [sources.md](sources.md).

## Gegnertypen (komplett laut Wiki) [O/HIGH ALS-S3]

| Typ | Eigenschaft |
|---|---|
| Basic | keine |
| Flying | nur von Air/Hybrid-Units angreifbar |
| Tank | mehr HP, etwas langsamer |
| Resistant | mehr HP, -50 % DoT-Schaden |
| Sprinter | schneller, weniger HP |
| Clone | weniger HP, spawnt bei Tod Basic-Gegner (Spawn-on-death) |
| Spawner | spawnt Basic-Gegner |
| Teleports | teleportiert zwischen Pfaden, verliert je Teleport 1/4 seiner HP |
| Avatar | immun gegen DoT und Vulnerability |
| Reinforced | -50 % Schaden von Full-AoE |
| Flawless | -50 % Schaden von Crits |
| Armored | nur Crits treffen, 2x Crit-Schaden |
| Boss | extrem viele HP, Tempo je Boss |
| Cyclone | Hybrid-Schaden -50 %, Hill +25 % |
| Earthbound | Hill -50 %, Ground +25 % |
| Shielded | Schild vor den HP |

Fehlt in der Liste: Stealth/Hidden, Regeneration [U/UNKNOWN].
