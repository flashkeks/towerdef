## Tower Stats (Noten) [O/HIGH ALS-S5]
Je Unit drei Noten (Damage, SPA, Range) von C- bis SSS. Spannen: Damage C- -10 % bis -6 %, B- 0,1 bis 3 %, A+ 15,1 bis 18 %, S 19,6 bis 21 %, SSS 23,9 bis 25 %; SPA bzw. Range analog ±12,5 % bis -10 %. Evolution hebt jede Note um 1 (5 % Chance auf doppelt), SSS wird perfekt. **Worthiness** +1 % je 75 Kills, erhöht Würfel-Qualität. Stat-Cube würfelt alle drei, Perfect Stat Cube eine einzelne Note.
