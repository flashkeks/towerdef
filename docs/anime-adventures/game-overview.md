## Core Gameplay Loop

```text
Lobby ──► Summon (Gems / Tickets / Event-Währung) ──► Team (Loadout) ──► Stage wählen
  ▲                                     (Story / Infinite / Legend / Raid / Portal / Challenge / Event / Dungeon)
  │                                                        │
  │                                                        ▼
  │                         Match: Units platzieren → Yen verdienen → Upgraden → Waves halten
  │                                                        │
  └── Belohnungen: Gems, Gold, Player-XP, Unit-XP, Items, Portale, Units, BP-Punkte ◄──┘
        │
        ├─► Units leveln (XP / XP-Food / Fusing) · Evolve (Items) · Traits rerollen · Stats rerollen · Limit Break (RR)
        └─► Shops (Gold Shop, Travelling Merchant, Raid-/Event-Shops) · Trading (handelbare Units, Skins, Relics)
```
RECONSTRUCTED · HIGH · [S72:Update Log, S72:Quests, S72:Summon, S73]

**Loadout-Größe:** Der Bestand nannte 6 Slots. Belegt ist nur, dass die Zahl der Slots am Spieler-Level hängt („Level requirement for unit slots reduced“, U14) und dass der Gamepass „Display All Units“ so viele Anzeige-Slots gibt wie Loadout-Slots [S72:Update Log, S72:Store]. Maximalzahl und Level-Schwellen: **UNKNOWN**. 6 gilt als Community-Konsens [OBSERVED · LOW · S53].

## Für unseren Nachbau

DESIGN-Vorschläge, keine AA-Werte:

- **Freischaltreihenfolge** als Datentabelle `unlocks[] = {feature, condition: {playerLevel?|stageCleared?|item?}}`. AA koppelt fast alles an Stage-Fortschritt und nur wenige Dinge an das Spieler-Level (Summon-Tiers, Trading, Codes). Das ist leicht zu warten. `DESIGN`
- **Versionierte Balance:** AA hat Level-Caps, Buff-Stacking (U17: addieren statt multiplizieren), Crit (U20.4.1) und Status-Stacking (U8) mehrmals umgestellt. Solche Regeln als Konfigurationsflags anlegen, nicht hart kodieren. `DESIGN`
- **NPC = Menüpunkt:** Jede Lobby-Funktion ist bei AA ein NPC mit eigenem Dialog. Im Web reicht eine Hub-Navigation mit denselben Funktionsknoten (Summon, Evolve, Traits, Stats, Shops, Modi, Leaderboards). `DESIGN`
- **Kein Pay-to-Win-Kopieren:** Gamepässe nur als Systemreferenz (Discount, Inventar, kosmetische Anzeige). Ob und wie wir monetarisieren, ist eine eigene Entscheidung. `DESIGN`
